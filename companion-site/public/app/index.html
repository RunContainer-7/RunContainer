Connect to your PC

This is the RunContainer companion. It shows an app that is running on your Windows PC and lets you use it from this phone. Nothing is installed or run on the phone itself.

  1. On the PC, open RunContainer → Settings → iPhone companion and turn it on.
  2. Type the six-digit code that card is showing.
  3. Tap Connect. The phone is remembered, so this happens once.

The code works once and expires after five minutes. If it runs out, ask for a new one on the PC.

Use the PC's web address instead

The address must start with https:// and end in .ts.net. A local 192.168.… address cannot be reached from a website, because the browser blocks it. This is only needed on a PC older than 0.11.3, which cannot hand out a code yet.
