How it works

Three steps, once.

After that, the icon on your home screen is the whole interface.

  1. 1

    Run the PC app

    Install RunContainer on Windows and turn on Settings → iPhone companion. It shows a six-digit code and its own web address.

  2. 2

    Add this site to your home screen

    Use the button above and follow the steps for your phone. From then on it opens full screen, like any other app.

  3. 3

    Enter the code

    Open the companion, type the code from the PC, and tap Connect. The phone is remembered, so this only happens once.

What you get

The PC, in your pocket.

Every running app

The companion lists what is running in RunContainer on the PC, with live status at a glance.

A real window

Tap an app to see its window live. Touches and scrolling land on the same point on the PC.

Type from the phone

A text field sends what you type, with Enter, Tab, Esc and the arrow keys a tap away.

From anywhere

Runs over Tailscale, so the phone only needs the internet — no port forwarding, no router setup.

Nothing on the phone

The phone is a window and a keyboard. The apps and their data stay on the PC.

Light or dark

Follows the phone, and remembers when you pick one. Nightly builds get their own icon.

Questions

Good to know.

Does the phone run the app?

No. The app runs in RunContainer on the Windows PC. The phone receives the picture and sends touches and keys back; nothing is installed or executed on the phone.

Do I need Tailscale?

Yes, on the PC. RunContainer gives the PC a private https://…ts.net address through Tailscale Funnel, so the phone can reach it from any network. Install Tailscale on Windows, sign in, and the address is offered in Settings → iPhone companion.

What if the PC is off?

The companion opens with the last list of apps it saw and says the PC is unreachable. Start RunContainer on the PC, then refresh.

Is it free?

Yes. The companion is part of RunContainer, and there is no account to create on the phone. The pairing code is the only thing you type.
